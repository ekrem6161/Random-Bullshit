================================================================
 C# ALISTIRMA SETI - INDeks
================================================================

 Bu klasorde 10 alistirma var. Her biri ayri bir kons projesidir
 ve Visual Studio ile veya terminalden calistirilabilir.

 NASIL CALISTIRILIR (Visual Studio):
   Alistirma klasorunu Visual Studio'da File > Open > Project ile
   ac. Program.cs dosyasini doldur. F5 ile calistir.

 NASIL CALISTIRILIR (terminal / komut satiri):
   dotnet run --project "01-IkiSayiToplama"

 Her Program.cs dosyasi su yapida:
   - En ustte   : PROBLEM metni (ne yapacaksin)
   - Ortada     : calistirilabilir iskelet kod + TODO isaretleri
   - En altta   : IPUCLARI (cozum degil, sadece yol gosterir)

 ONCE ISLETMESI GEREKENLER:
   - Calistirdiktan sonra ekran hemen kapanir. Dosyanin en sonuna
     Console.ReadKey(); ekle. (Ipucu olarak her dosyada yazili.)
   - TODO satirlarini kendin yazarsan burada cozum yok.

 Sirayla cozmek en faydalisi. Zorluk arttikca konular bir

================================================================
 EN COK KARSILASILAN 3 HATA
================================================================

 1) Ortalama yanlis cikiyor
    int / int -> int yapar, ondalik kisi kaybolur.
    (125 + 50 + 30) / 3   = 68   <- yanlis
    (125 + 50 + 30) / 3.0 = 68.33 <- dogru
    Bolme operatorunun sagina 3.0 yaz.

 2) Metin ile sayiyi birlikte yazdiramiyorum
    Toplam string degisse hata verir.
    + ile:  Console.WriteLine("Toplam: " + toplam);
    $ ile:  Console.WriteLine($"Toplam: {toplam}");   (onerilen)

 3) if / else if zinciri calismiyor
    Kosullari genisten daraya yaz. Once not >= 60 kontrol
    edersen, 85 notu AA veya BA kontrolune hic gelmez.
